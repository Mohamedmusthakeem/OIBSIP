# Unemployment Analysis with Python

## Oasis Infobyte Data Science Internship — Task 2

### Project Overview

This project performs Exploratory Data Analysis (EDA) on unemployment data from India to identify regional and temporal trends, with a focus on changes during the COVID-19 pandemic.

### Objective

To analyze unemployment patterns across different regions and time periods using Python, pandas, matplotlib, and seaborn.

### Dataset

Dataset: **Unemployment in India**

The dataset contains unemployment and labour-market indicators for different regions of India.

### Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

### Analysis Performed

The project includes:

1. Dataset loading and inspection
2. Data cleaning and preprocessing
3. Shape, data types, and missing-value analysis
4. Descriptive statistical analysis
5. Region-wise average unemployment rate
6. Month-wise unemployment trends
7. Time-series analysis for selected major states
8. Top 10 regions with highest average unemployment rate
9. Correlation analysis using a heatmap
10. Pre-COVID vs Post-COVID comparison
11. Key findings and conclusions

### Visualizations

The project includes:

- Region-wise average unemployment bar chart
- Month-wise unemployment trend line chart
- State-wise unemployment time-series chart
- Top 10 regions bar chart
- Correlation heatmap
- Pre-COVID vs Post-COVID comparison chart

### COVID-19 Analysis

The dataset was divided into Pre-COVID and Post-COVID periods using a date-based analysis cutoff. Mean unemployment and labour-market indicators were calculated for both periods to observe changes.

### Key Findings

- Unemployment rates vary across different regions of India.
- Monthly analysis reveals changes in unemployment over time.
- Regional time-series analysis shows differences in unemployment patterns.
- The top-10 analysis identifies regions with relatively higher average unemployment rates.
- Correlation analysis shows relationships among unemployment rate, estimated employment, and labour participation rate.
- The Pre-COVID and Post-COVID comparison provides a quantitative view of changes in unemployment-related indicators.
