# Task 3 — Car Price Prediction

## Oasis Infobyte Data Science Internship

### Problem Statement
Predict the selling price of a used car using its features and machine learning regression algorithms.

### Objective
- Explore and analyze the car dataset.
- Understand factors associated with used car prices.
- Train and compare regression models.
- Evaluate model performance using regression metrics.
- Predict the selling price of a sample car.

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

### Dataset
The project uses a used-car dataset containing features such as manufacturing year, present price, kilometres driven, fuel type, selling type, transmission, owner count, and selling price.

### How to Run
1. Open `Car_Price_Prediction_OIBSIP.ipynb` in Google Colab.
2. Upload the dataset CSV when prompted.
3. Run the notebook cells sequentially.

### Models Used
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

### Model Evaluation
Models are compared using:
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

### Results and Output
The notebook includes exploratory visualizations, model comparison, actual-versus-predicted analysis, residual analysis, and a sample car price prediction.

### Screenshots
Screenshots of the dataset analysis, model comparison, evaluation plots, and prediction output will be added here.

### Conclusion
This project demonstrates how regression algorithms can estimate used-car selling prices from vehicle features. Predictions depend on the dataset and should not be treated as guaranteed market prices.
